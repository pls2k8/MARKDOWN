## すでに片側の副腎を摘出して状況下で、残された副腎に腫瘍が生じた

<small>Tumor development in the remaining adrenal gland following contralateral adrenalectomy</small>

すでに片側の副腎を摘出済の状況下で、残された副腎に腫瘍が生じた場合の生命予後とQOL（生活の質）をどう両立させるかという問題。

私は、このケースでは治療の選択肢を最初から手術だけに絞らず、次の5つの方向から包括的に検討する必要があると考えます。
1. 悪性化・転移の有無を正確に評価する。
2. 残された副腎の機能をできる限り温存する。
3. 手術以外の局所治療を検討する。
4. 転移や進行が確認された場合の全身治療を検討する。
5. 治療後の副腎機能低下と日常生活への影響を最小限にする。
特に重要なのは、悪性の可能性が出てきたことと、直ちに副腎を全部摘出しなければならないことは同義ではないという点です。

また、褐色細胞腫は病理組織の見た目だけで良性・悪性を確実に区別することが難しく、転移の確認が重要になります。

１．現段階で、確認すべきこと：本当に褐色細胞腫なのか？
現在、残された副腎に確認されている腫瘍が、どのような性質のものなのかを正確に見極める必要があります。

副腎腫瘍には、脂肪を含む良性の腺腫、カテコールアミンを産生する褐色細胞腫、周囲への浸潤や遠隔転移を伴う腫瘍などがあります。それぞれ治療方針が異なるため、画像検査やホルモン検査などによる評価が重要です。

また、褐色細胞腫は病理組織の形だけで良性・悪性を確実に判断することが難しく、肝臓、肺、骨、リンパ節などへの転移の有無が重要な判断材料になります。

現在の腫瘍が、過去に摘出した褐色細胞腫と同じ性質であるとは限りません。したがって、悪性化の可能性だけでなく、別の種類の良性腫瘍である可能性も考慮し、まずは腫瘍の正体を正確に把握することが大切です。

2. 悪性化が疑われた場合の治療選択肢
大きく分けて6つあります。
① 経過観察・慎重な監視
副腎機能温存を優先
腫瘍が小さく、画像上の変化が乏しく、ホルモン異常や症状が認められない場合には、直ちに手術をせず経過を見る選択肢があります。

主な検査は次のとおりです。
- MRI・CTによる腫瘍の大きさと性状の確認
- 血中または尿中の分画メタネフリン
- 血圧、脈拍などの確認
- 必要に応じて機能画像検査
- コルチゾール、ACTHなどの副腎機能評価
腫瘍の大きさだけでなく、増大速度、ホルモン分泌、画像上の特徴を総合して判断します。

現在、半年ごとの検査になっていることは、腫瘍の悪性化が確定したという意味ではありません。

②副腎部分切除術（Partial Adrenalectomy）
特に重要な選択肢
今回のケースで、私
主治医が特に重視したいとおっしゃった選択肢です。
通常の副腎摘出術では副腎全体を取り除きますが、部分切除術では腫瘍部分を取り除き、正常な副腎皮質を可能な限り残します。

メリットは、
- 副腎ホルモンの自己分泌能力を残せる可能性がある。
- 生涯にわたるホルモン補充への依存を避けられる可能性がある。
- 副腎不全や副腎クリーゼのリスクを軽減できる可能性がある。
- 日常生活の自由度を維持できる可能性がある。
一方で、注意点もあります。
- 腫瘍を完全に取り切れない可能性がある。
- 残した副腎組織に腫瘍が再発する可能性がある。
- 残存組織が十分なホルモンを分泌できる保証はない。
- 悪性が疑われる場合、腫瘍の完全切除を優先すべきケースがある。
2025年改訂の日本内分泌学会ガイドラインでも、両側性病変のリスクがある褐色細胞腫や、反対側の副腎をすでに摘出した患者について、副腎部分切除を検討することが示されています。ただし、推奨の根拠の強さは限定的です。

つまり、今回のように片側がすでに存在しない場合は、通常の褐色細胞腫とは異なる手術上の判断が必要になります。
③ 腫瘍部分への局所治療
手術で副腎全体を取り除くことを避けたい場合、腫瘍の位置や大きさによっては局所治療も検討対象になります。

代表的なものは、熱で腫瘍細胞を壊すラジオ波焼灼術（RFA）、腫瘍を凍結して破壊する凍結療法、そして放射線で腫瘍の増殖を抑える放射線治療です。
これらは、すべての副腎腫瘍に適用できるわけではありません。

特に褐色細胞腫は血圧を急激に上昇させる物質を分泌する場合があるため、焼灼などの処置にも慎重な準備が必要です。

局所治療は、副腎機能を温存できる可能性がある一方、褐色細胞腫に対する標準的な根治治療として確立しているわけではありません。

④ 副腎全摘出術
これは腫瘍の完全切除を優先する場合の選択肢です。

ただし、今回のケースでは非常に大きな問題が生じます。

残された副腎を全部摘出すると、原則として自力で必要な副腎皮質ホルモンを十分に作れなくなります。

その結果、次のような対応が生涯必要になります。
- 糖質コルチコイド（ヒドロコルチゾンなど）の補充
- 必要に応じて鉱質コルチコイド（フルドロコルチゾンなど）の補充
- 発熱、感染症、手術などの際のステロイド増量
- 緊急時の自己注射などの備え
- 副腎クリーゼを防ぐための知識と管理

副腎不全は単に薬を毎日飲めば済むという問題ではありません。

嘔吐や下痢などで薬を吸収できない場合、感染症や外傷などでホルモン需要が増加した場合には、急激な血圧低下や意識障害を伴う副腎クリーゼが起きる可能性があります。

一方で、必要なホルモン補充と緊急時対応を適切に身につければ、両側副腎摘出後も生活を維持することは可能です。

したがって、全摘出は絶対に避けるべき治療ではありませんが、今回のケースでは、その代償を十分に理解したうえで判断する必要があります。

今回のケースで特に重要になる3つの論点
ここからは、これまで伺っている経過も踏まえて考えます。
論点A：残された副腎をどこまで温存できるか
20年以上前に片側の副腎を摘出しているため、残存副腎は単なるもう一方の臓器ではありません。

生命維持に必要な副腎皮質ホルモンを自力で作る、唯一の副腎です。

したがって、治療方針を決める際には、次の優先順位を検討する意味があります。
1. 腫瘍の性質と進行リスクを正確に把握する。
2. 腫瘍の完全切除が必要か判断する。
3. 部分切除が可能か専門医に評価してもらう。
4. 部分切除が困難なら局所治療などの可能性を検討する。
5. 全摘出が必要なら、副腎不全への長期対応を含めて決定する。
特に、部分切除が可能かどうかは、腫瘍の位置、血管との関係、残せる副腎皮質の量、悪性の疑いなどに左右されます。
論点B：腫瘍の悪性度と増殖速度を分けて考える
仮に悪性が疑われたとしても、すべての腫瘍が同じ速度で進行するわけではありません。

例えば、
- 腫瘍が少しずつ大きくなっている。
- ホルモン分泌が増加している。
- 周囲組織への浸潤が疑われる。
- リンパ節や肺、肝臓、骨などに転移がある。
これらはそれぞれ意味が異なります。

腫瘍が存在するという事実だけで、直ちに全摘出を選択する必要があるわけではありません。

一方、明確な浸潤や転移がある場合には、腫瘍の完全切除や全身治療を優先する必要が出てきます。
論点C：副腎機能の現在地を正確に把握する
これまで伺った検査結果には、メタネフリン、ノルアドレナリン、ドーパミン、コルチゾール、ACTHなどがあります。

これらは今後の治療方針を考えるうえで重要な情報になります。

特に、次の2つは分けて評価する必要があります。
- 腫瘍がカテコールアミンを過剰に分泌していないか。
- 残された副腎が生命維持に必要なホルモンを十分に分泌できているか。
この2つは同じ問題ではありません。
5. 主治医に確認しておきたい質問
次回の診察では、以下の質問を準備しておくと、治療の選択肢が具体化すると思います。
1. 現在の脂肪を含む腫瘍は、副腎腺腫と考えてよいのか。それとも褐色細胞腫の可能性も残っているのか。
2. 現在の腫瘍の大きさ、位置、画像上の特徴から、部分切除は技術的に可能なのか。
3. 将来、悪性が疑われた場合、部分切除と全摘出の判断基準は何か。
4. ラジオ波焼灼術や凍結療法など、副腎機能を温存する局所治療の適応はあるのか。
5. 全摘出が必要になった場合、術後の副腎不全管理をどのように行うのか。
6. 褐色細胞腫の遺伝子検査を受ける意義はあるのか。

腫瘍への対応とQOLの両立
第一段階：現状の正確な把握

腫瘍の性質、増殖速度、ホルモン分泌、転移の有無を確認する。


第二段階：副腎温存の可能性を追求

部分切除や局所治療など、残存副腎の機能を維持できる方法を検討する。


第三段階：必要な場合は腫瘍制御を優先

全摘出や放射性医薬品、化学療法なども含め、生命予後を守る治療を選択する。


第四段階：治療後の生活の質を守る

ホルモン管理、日常生活、身体活動、心理的負担まで含めて長期的に管理する。
